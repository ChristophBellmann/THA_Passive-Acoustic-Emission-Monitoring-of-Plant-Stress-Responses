# Artifact Discrimination

Artifact discrimination is central to this project because laboratory and building environments contain many narrow-band electrical and mechanical signals.

## Strategy

The project combines several checks:

- comparison against a passive reference channel,
- cross-channel coherence,
- proximity to known harmonic families,
- signal-to-noise metrics,
- temporal behavior,
- controlled interventions,
- comparison between different mechanical coupling paths.

## Known structural artifact

The previously investigated feature around 6.6–6.75 kHz was traced to a harmonic of a building-related 750 Hz source. It is retained in the documentation as a useful negative result.

## Candidate versus conclusion

A signal can be statistically interesting without being biological. Frequency drift, localization and response to watering can strengthen a hypothesis, but alternative physical mechanisms still need to be excluded.

This distinction is maintained throughout the documentation.
