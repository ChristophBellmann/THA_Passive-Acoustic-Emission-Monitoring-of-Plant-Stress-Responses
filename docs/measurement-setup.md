# Measurement Setup

The contact-based setup uses a Rigol DS1104Z oscilloscope for multi-channel acquisition.

## Acquisition

A representative acquisition configuration documented by the project uses:

- 500 kSa/s sampling,
- 300,000 samples per frame,
- 0–250 kHz Nyquist range,
- repeated frames during continuous day/night monitoring.

## Sensor roles

The current experimental arrangement distinguishes a passive reference channel from amplified plant/root-zone and metal-coupled channels. This allows cross-channel comparisons instead of relying on a single sensor.

A particularly important design principle is the reference channel: signals that appear similarly in the reference and plant channels are less convincing as local plant-related phenomena.

## Experimental character

Sensor coupling, amplifier behavior, mechanical mounting and the measurement environment all influence the recorded spectrum. Consequently, the setup is documented as an experimental measurement chain rather than a calibrated biological instrument.
